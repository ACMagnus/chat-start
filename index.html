FEATURES

启动器能做什么

不需要正版账号，也不用另外安装 Java；版本、依赖和资源由启动器统一管理。

纯离线昵称登录

填写玩家昵称即可进入游戏，自动生成离线标识，不连接正版认证服务器，昵称自动保存在本地。

在线下载游戏版本

拉取正式版、快照与旧版清单，自动下载客户端、依赖库、本地库和资源；官方源与国内公益镜像互相备用，已装版本可在界面上一键删除。

下载完整性校验

每个文件都做 SHA-1 哈希和大小双重校验，损坏自动重下；已下载且校验通过的文件会自动跳过。

联机服务器与开房

保存常用服务器，直接粘贴 IP:端口自动拆分、启动后直连；本地开房后自动列出内网与公网地址，一键复制发给朋友。

模组中心

在线搜索 Modrinth 模组库，自动按当前游戏版本和 Fabric / Forge / NeoForge / Quilt 加载器筛选匹配版本，一键下载装进 mods；本地模组仍可启用、禁用、添加、删除。

日志回显与启动检查

启动前检查游戏主程序、依赖库和资源索引是否齐全；游戏运行日志实时显示在启动器窗口里。

GET STARTED

三步进入游戏

1

解压并打开

解压下载到的压缩包，双击里面的「启动游戏.bat」；不需要安装 Java，程序自带运行环境。

2

下载想要的版本

点「下载新版本」，选好下载源和版本后安装，客户端、依赖和资源会自动下载到游戏目录。

3

填昵称进入游戏

回到主界面填玩家昵称，选中刚装好的版本，点「进入游戏」；下过的版本之后离线也能启动。

Java 运行时已内置，自动匹配版本

  • 包内自带 Java 17，直接运行 1.17 ～ 1.20.4 等需要 Java 17 的版本。
  • 包内自带 Java 21，1.20.5 ～ 1.21.x 启动时自动选用，无需另外安装。
  • 包内自带 Java 25，25.x / 26.x 等最新快照启动时自动选用。
  • 1.16.5 及更早旧版通常要求 Java 8，可由内置 Java 17 兼容运行；个别旧版异常再到设置里切换。
  • 点启动前会自动核对 Java 版本，版本过低时直接弹出中文提示并停止，不会直接崩溃。

FAQ

常见问题

双击启动器没反应怎么办？
双击「排错模式（双击看报错）.bat」，会保留黑窗口并显示具体报错；把最后的错误信息对照说明.txt 排查。常见原因是缺少对应版本的 Java 运行时，或游戏文件没有下载完整。
下载某个版本一直失败或超时？
在下载窗口把下载源在国内镜像和 Mojang 官方源之间切换重试；镜像节点繁忙时，切换到官方源通常更稳定。每个文件校验失败会自动重下。
联机为什么进不去别人的服务器？
加入的服务器必须是离线模式（关闭正版验证 online-mode=false），离线昵称才能进入。外网联机需要路由器端口映射，或使用虚拟局域网组网。
启动器里包含游戏本体吗？
不包含。启动器只负责版本清单获取与文件下载调度，游戏文件由你的设备联网从 Mojang 官方源或公益镜像下载到本地，启动器不内置、不预分发任何 Minecraft 游戏文件。
游戏存档存在哪里？
存档保存在游戏目录的 saves 文件夹内，默认位置为 C:\Users\你的用户名\.minecraft\saves；卸载启动器不会删除已有存档。
