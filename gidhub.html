README.md

chat start

一款 Minecraft Java 版离线启动器，界面按 PCL2 重做。双击即用，内置运行时，不需要另装 Java。

下载页 · 最新版本 v1.11.14 · 官网

能做什么

  • 离线 / 微软 / 正版三种登录入口，离线模式填个昵称就能进游戏
  • 版本下载：正式版、快照、旧版全量清单，BMCLAPI 镜像与官方源互备
  • 整合包一键安装：Fabric / Quilt / Forge / NeoForge，自动补原版依赖
  • 模组、光影、资源包在线浏览与安装，本地已装内容单独管理
  • 皮肤库、联机服务器、开房间、运行日志与一键复制

下载

最新成品在 Releases · v1.11.14，文件名 chat-start-.zip，解压后双击 chat-start.exe 或 launcher.jar。

说明

这是个人项目，不是 PCL2 官方作品；界面参考 PCL2 的布局，名字、署名与官网均保持 chat start / 竹下一刀魂。
